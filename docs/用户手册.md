# LiveEmail 用户手册

LiveEmail 是一款 Windows 桌面邮件客户端，支持多账户、统一收件箱、全文搜索、离线阅读与系统通知。邮件数据保存在本机，密码与令牌保存在 Windows 凭据管理器。

## 1. 系统要求

- Windows 10 21H2 及以上 / Windows 11，x64
- 需要 WebView2 运行时（Windows 11 自带；Windows 10 如缺失，安装包会自动提示安装）
- 网络需允许访问 IMAP（993/143）与 SMTP（465/587）端口

## 2. 安装与卸载

1. 运行 `LiveEmail_0.1.0_x64-setup.exe`。
2. 安装程序默认安装到当前用户目录，无需管理员权限。
3. 卸载：Windows「设置 → 应用 → 已安装的应用 → LiveEmail → 卸载」。
4. 卸载默认保留 `%APPDATA%\com.liveemail.app` 下的本地邮件缓存；如需彻底清除，请手动删除该目录，并在「Windows 凭据管理器 → Windows 凭据」中删除 `com.liveemail.app` 开头的条目。

## 3. 添加账户

打开「账户 → 添加账户」，选择服务商预设，填写邮箱地址与凭据。

### 3.1 QQ 邮箱

1. 登录 QQ 邮箱网页版 →「设置 → 账户」。
2. 开启「IMAP/SMTP 服务」。
3. 按提示生成「授权码」，将授权码填入 LiveEmail 的密码框（不是 QQ 登录密码）。
4. 预设已自动填写 `imap.qq.com:993` 与 `smtp.qq.com:465`。

### 3.2 163 / 126 邮箱

1. 登录邮箱网页版 →「设置 → POP3/SMTP/IMAP」。
2. 开启 IMAP/SMTP 服务，设置「客户端授权密码」。
3. 将客户端授权密码填入 LiveEmail。
4. 预设：`imap.163.com:993` / `smtp.163.com:465`（126 同理）。

### 3.3 自建 / 企业 IMAP

选择「自定义」，填写 IMAP 与 SMTP 主机、端口和加密方式：

- SSL/TLS：IMAP 993、SMTP 465
- STARTTLS：IMAP 143、SMTP 587
- 内网无加密服务器可选择「不加密」，但不推荐

填写后可先点「测试连接」，确认 IMAP 与 SMTP 均通过再保存。

### 3.4 Gmail（OAuth2）

Gmail 已停用「账号密码 + IMAP」的基本认证，需要 OAuth2：

1. 打开 [Google Cloud Console](https://console.cloud.google.com/)，创建项目。
2. 「API 和服务 → 库」中启用 **Gmail API**。
3. 「API 和服务 → OAuth 同意屏幕」：选择外部用户，填写应用名称与支持邮箱；测试阶段把自己的 Gmail 加入测试用户。
4. 「凭据 → 创建凭据 → OAuth 客户端 ID」：
   - 应用类型选择 **桌面应用**
   - 记录 **Client ID** 与 **Client Secret**
5. 在 LiveEmail 中添加账户：
   - 服务商选择 Gmail
   - 认证方式选择「OAuth2（Gmail / Outlook）」
   - 填入 Client ID 与 Client Secret
   - 邮箱地址填写要登录的 Gmail 地址
   - 保存
6. 在账户列表点击「授权」，系统浏览器会打开 Google 登录页；授权完成后回到 LiveEmail。
7. 点击「测试」验证 IMAP 与 SMTP。

> 令牌过期时会自动使用 refresh token 续期，无需重复授权。若在 Google 控制台撤销了授权，需要重新点击「授权」。

### 3.5 Outlook.com（OAuth2）

1. 打开 [Microsoft Entra 管理中心](https://entra.microsoft.com/) →「应用注册 → 新注册」。
2. 账户类型按需选择（个人 Microsoft 账户可选「个人 Microsoft 账户」或「任何组织目录中的账户和个人账户」）。
3. 「重定向 URI」选择平台 **移动和桌面应用程序**，添加 `http://localhost`。
4. 记录「应用程序（客户端）ID」。
5. 「API 权限」添加：
   - `IMAP.AccessAsUser.All`
   - `SMTP.Send`
   - `offline_access`
   - `openid`、`email`
6. 在 LiveEmail 中添加账户：
   - 服务商选择 Outlook.com
   - 认证方式选择 OAuth2
   - 填写 Client ID；Tenant 可留空（默认 `common`）或填写租户 ID
   - 保存后在账户列表点击「授权」

### 3.6 授权码手动兜底

如果企业代理或安全软件拦截了 `127.0.0.1` 回调，OAuth 授权会超时。此时：

- 改用服务商提供的应用专用密码 / 授权码（若服务商支持），认证方式选择「密码 / 授权码」；
- 或联系管理员放行本机回环地址。

## 4. 日常使用

### 4.1 收信与阅读

- 左侧切换统一收件箱或具体账户 / 文件夹。
- 点击邮件即标记已读；未读、星标、附件在列表中有标识。
- 阅读窗格顶部可回复、全部回复、转发、归档、删除、星标。
- HTML 邮件默认不加载远程图片；需要时在邮件顶部点击加载。图片附件可直接预览。

### 4.2 撰写与发送

- 点击「写邮件」或按 `C`。
- 支持富文本 / 纯文本切换、链接、图片、附件与签名。
- 草稿会自动保存，关闭窗口不会丢失；可从「草稿」入口恢复。
- 发送失败会进入「设置 → 发送队列」，可一键重试。
- 发送成功后会自动追加到服务器的「已发送」文件夹。

### 4.3 搜索与筛选

- 顶部搜索框输入关键词，支持主题、发件人和正文。
- 列表上方可切换「未读 / 星标 / 含附件」筛选。
- 搜索在本地 SQLite FTS5 上执行，断网也可用。

### 4.4 快捷键

| 按键 | 功能 |
|------|------|
| `C` | 写新邮件 |
| `R` | 回复 |
| `F` | 转发 |
| `/` | 聚焦搜索框 |
| `E` | 归档 |
| `#` | 删除 |
| `U` | 标为未读 |
| `S` | 切换星标 |

## 5. 设置

- **主题**：跟随系统 / 浅色 / 深色
- **字体大小**：小 / 标准 / 大
- **同步间隔**：1 / 5 / 15 / 30 分钟；IDLE 推送开启时新邮件仍会即时到达
- **通知与托盘**：可关闭系统通知或关闭「最小化到托盘」
- **远程图片**：默认阻止；开启后会始终加载（可能泄露阅读状态）
- **存储管理**：查看数据库、附件缓存占用，按范围清理缓存
- **检查更新**：从发布源检查并安装新版本

## 6. 隐私与安全

- 密码、授权码、OAuth2 访问令牌与刷新令牌仅保存在 Windows 凭据管理器，不写入 SQLite，也不打印到日志。
- 与邮件服务器的连接使用 TLS 1.2+，证书由系统信任链校验。
- 邮件 HTML 在渲染前经过 DOMPurify 净化，脚本、事件处理器与危险 URL 会被移除。
- 邮件数据仅保存在本机；应用不包含统计、广告或第三方追踪。
- 本地缓存默认不加密。如需在共享电脑上使用，建议启用 Windows 账户登录密码并定期清理缓存。

## 7. 常见问题

**Q：提示「认证失败」怎么办？**

- QQ / 163 必须使用授权码，不是登录密码。
- Gmail / Outlook 需要使用 OAuth2 并完成「授权」。
- 确认服务商后台已开启 IMAP/SMTP。
- 企业邮箱可能需要单独申请客户端授权。

**Q：提示证书错误 / 无法连接？**

- 检查系统时间是否正确（TLS 证书校验依赖时间）。
- 公司网络可能拦截 993/465 端口，尝试 STARTTLS（143/587）。
- 自签名证书服务器目前会拒绝连接，请使用受信任证书。

**Q：收不到新邮件通知？**

- 确认「设置 → 新邮件系统通知」已开启。
- Windows「设置 → 系统 → 通知」中允许 LiveEmail 通知。
- 若服务商不支持 IDLE，最多会等待一个同步间隔。

**Q：关闭窗口后程序还在运行？**

- 默认关闭到托盘，这是预期行为。可在设置中关闭「关闭窗口时最小化到托盘」，或右键托盘图标选择退出。

**Q：如何备份邮件？**

- 邮件与附件位于 `%APPDATA%\com.liveemail.app`。退出应用后复制该目录即可。
- 凭据不在该目录中，恢复后需要重新输入密码 / 授权码。

**Q：安装包为什么很小？**

- LiveEmail 使用系统 WebView2 与 Rust 原生后端，不打包 Chromium，因此安装包约 4MB。

## 5. 安全与隐私复查

| 检查项 | 结论 |
|--------|------|
| 凭据存储 | Windows 凭据管理器（keyring），数据库不存明文密码/令牌 |
| OAuth2 | PKCE S256、`state` 校验、回环地址随机端口、刷新令牌加密存储 |
| 传输安全 | IMAP/SMTP 强制 SSL/STARTTLS；不支持明文降级 |
| HTML 渲染 | DOMPurify 净化 + 外链拦截 + CSP 禁止内联脚本 |
| CSP | `default-src 'self'`，图片允许 `https:`/`data:`/`blob:`，连接仅 `self`/`ipc:` |
| 权限 | 仅 opener/notification/dialog/store/updater，无文件系统通配权限 |
| 隐私 | 无遥测、无广告、无第三方统计；仅连接用户配置的邮箱与更新源 |
| 仓库卫生 | `.key`/`.key.pub`/`.sig`/`latest.json`/`target` 已加入 `.gitignore` |

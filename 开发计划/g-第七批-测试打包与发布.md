# g. 第七批 —— 测试、打包与发布

> 目标：完成测试覆盖与 Windows 打包发布，达到可交付状态。
> 前置：第六批（功能与体验冻结）。

## 一、目标与交付物

1. 单元测试（Rust + TS）与关键链路集成测试。
2. Windows 安装包（NSIS/MSI）与图标品牌。
3. 自动更新（tauri-plugin-updater）。
4. 发布物（安装包 + 更新签名 + 说明文档）。

## 二、任务清单

### 1. 测试
- [ ] Rust 单元测试：MIME 解析、游标增量逻辑、凭据存储、FTS 查询
- [ ] TS 单元测试：组件与状态逻辑（Vitest + Testing Library）
- [ ] 集成测试：连接 → 同步 → 阅读 → 发送 → 操作 主链路（多服务商）
- [ ] 边界测试：断网重连、大附件、超长邮件、异常 HTML、账号认证失败
- [ ] 缺陷修复至无 P0/P1

### 2. 打包
- [ ] Windows x64 打包（NSIS 安装器 + MSI 可选）
- [ ] 应用图标全套尺寸与品牌（窗口/托盘/安装器）
- [ ] 安装/卸载/升级验证（覆盖安装、用户数据保留）
- [ ] 安装包体积与启动内存复测（对齐 5.x 非功能指标）

### 3. 更新与发布
- [ ] 配置 `tauri-plugin-updater`：更新签名公钥、更新源 manifest
- [ ] 发布到 GitHub Releases（安装包 + 更新 manifest + 校验和）
- [ ] 更新流程端到端验证（旧版本 → 提示 → 更新成功）
- [ ] 编写用户文档：快速开始、账户添加指引（各服务商）、常见问题

### 4. 发布检查
- [ ] 安全复查（凭据/CSP/权限）与隐私说明
- [ ] 版本号、变更日志（CHANGELOG）
- [ ] 验收对照 [需求文档](../需求文档.md) 第 7 节里程碑逐项确认

## 三、验收标准

- [ ] 主链路集成测试通过，无 P0/P1 缺陷
- [ ] Windows 安装包可安装、可卸载、可升级，用户数据不丢失
- [ ] 自动更新从旧版本成功升级到新版本
- [ ] 安装包 ≤ 15MB，冷启动 ≤ 2 秒，常驻内存 ≤ 200MB
- [ ] 发布物齐全：安装包、更新 manifest、用户文档、CHANGELOG

## 四、涉及模块

- `src-tauri/tests/`、`src/**/*.test.tsx`
- `src-tauri/tauri.conf.json`（updater/签名）、CI 流水线

## 五、风险与注意

- 自动更新需要签名与公钥/私钥管理，私钥严禁入库。
- 升级需保证数据库迁移向后兼容（migration 版本管理）。
- 首次发布建议先在 GitHub Releases 灰度，收集崩溃与反馈再全面推广。

# f. 第六批 —— 设置、安全与体验优化

> 目标：补齐设置与个性化能力，完成安全加固与性能打磨。
> 前置：第五批（功能已基本完整）。

## 一、目标与交付物

1. 设置面板（通用/账户/通知/快捷键/存储）。
2. 明暗主题、字体字号、签名管理。
3. 快捷键系统。
4. 安全加固（凭据、CSP、日志脱敏、本地缓存加密可选）。
5. 性能优化（虚拟列表、渲染节流、启动耗时）。

## 二、任务清单

### 1. 设置
- [ ] 通用：语言（中文首发）、主题（明/暗/跟随系统）、字体字号
- [ ] 账户设置入口（复用第一批）
- [ ] 通知偏好：开关、声音、免打扰时段
- [ ] 存储管理：缓存/附件占用显示、一键清理、附件保留策略
- [ ] 签名管理：默认 + 按账户 + 回复前缀
- [ ] 数据导入导出（配置与账户，不含凭据，P2）

### 2. 快捷键
- [ ] 全局快捷键注册（tauri-plugin-global-shortcut，按需）
- [ ] 应用内快捷键表：撰写 C、回复 R、转发 F、搜索 /、删除 #、归档 E、已读 U、星标 S、切换账户
- [ ] 快捷键设置页（可自定义，P2）

### 3. 安全加固
- [ ] 凭据审计：确认密码/授权码/令牌仅存 keyring，日志脱敏
- [ ] CSP 收紧与 Tauri Capability 最小权限复查
- [ ] 附件路径遍历防护（下载文件名消毒）
- [ ] 本地缓存 AES-256-GCM 加密（主密钥存 keyring，P2 可选）

### 4. 性能与体验
- [ ] 启动耗时优化（懒加载、首屏最小渲染）
- [ ] 列表渲染节流、React Query 缓存调优
- [ ] 空状态 / 加载态 / 错误态统一组件
- [ ] 明暗主题切换无闪烁

## 三、验收标准

- [ ] 主题/字体/签名/通知设置生效并持久化
- [ ] 快捷键全部可用且不冲突
- [ ] 存储清理后缓存/附件空间释放，数据显示正确
- [ ] 安全审计：无凭据明文落盘/落日志，CSP 无告警
- [ ] 冷启动 ≤ 2 秒，常驻内存 ≤ 200MB（单账户基准）

## 四、涉及模块

- `src/features/settings/`、`src/lib/`、`src/store/`
- `src-tauri/src/services/`（安全加固、存储管理）

## 五、风险与注意

- 明暗主题需贯穿全部组件，避免遗漏硬编码颜色。
- 附件文件名消毒是安全必须项，防止 `../` 与特殊字符。
- 快捷键需避免与系统/输入法冲突，提供自定义出口。

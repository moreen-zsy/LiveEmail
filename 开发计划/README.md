# LiveEmail 分批开发计划

> 关联：[需求文档](../需求文档.md) · [技术选型 v2.0](../邮箱客户端-技术选型文档-v2.0.md)
> 批次划分原则：每批为**可独立交付、可验证**的增量；前一批是后一批的前置。

## 批次总览

| 批次 | 文档 | 交付主题 | 核心验收 |
|------|------|---------|---------|
| a. 第一批 | [第一批-项目脚手架与账户体系](./a-第一批-项目脚手架与账户体系.md) | 脚手架、数据库 Schema、账户 CRUD、OAuth2/授权码连接测试 | 至少 Gmail + QQ 账户可添加并连接成功 |
| b. 第二批 | [第二批-邮件接收与阅读](./b-第二批-邮件接收与阅读.md) | IMAP 同步、MIME 解析、邮件列表/阅读器、HTML 净化 | 万封邮件完整同步并安全渲染 |
| c. 第三批 | [第三批-邮件撰写与发送](./c-第三批-邮件撰写与发送.md) | Tiptap 富文本、附件、草稿、SMTP 发送队列 | 富文本+附件邮件成功送达，草稿可恢复 |
| d. 第四批 | [第四批-文件夹与邮件操作](./d-第四批-文件夹与邮件操作.md) | 文件夹同步、移动/删除/星标/归档、多账户 | 操作与服务器状态一致 |
| e. 第五批 | [第五批-搜索与同步引擎](./e-第五批-搜索与同步引擎.md) | FTS5 搜索、增量同步引擎、IDLE、通知 | 全文搜索可用，新邮件实时提醒 |
| f. 第六批 | [第六批-设置安全与体验优化](./f-第六批-设置安全与体验优化.md) | 设置面板、主题/快捷键/签名、安全加固、性能 | 设置生效，凭据不落明文 |
| g. 第七批 | [第七批-测试打包与发布](./g-第七批-测试打包与发布.md) | 测试、Windows 打包、自动更新、发布 | 可安装、可升级、无 P0/P1 缺陷 |

## 依赖关系

```
a 第一批（脚手架+账户）
   └─▶ b 第二批（接收+阅读）
          └─▶ c 第三批（撰写+发送）
                 └─▶ d 第四批（操作+文件夹）
                        └─▶ e 第五批（搜索+同步引擎）
                               └─▶ f 第六批（设置+安全+体验）
                                      └─▶ g 第七批（测试+打包+发布）
```

> 每批文档包含：目标、前置、任务清单（可勾选）、验收标准、涉及模块、风险注意。

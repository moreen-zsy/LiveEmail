# d. 第四批 —— 文件夹与邮件操作

> 目标：补齐文件夹体系与邮件操作，并保证本地操作与服务器状态一致。
> 前置：第三批（已可收发）。

## 一、目标与交付物

1. 文件夹完整同步（收件箱/已发送/草稿/垃圾/归档/自定义）。
2. 邮件操作：已读/未读、星标、移动、删除、归档、标记垃圾。
3. 批量操作（多选）。
4. 多账户切换与各账户文件夹独立视图。

## 二、任务清单

### 1. 文件夹
- [ ] `folders` 同步：LIST 拉取全部文件夹（含层级/分隔符），与本地表对齐
- [ ] 特殊文件夹映射：INBOX/Sent/Drafts/Trash/Junk/Archive 识别为系统文件夹
- [ ] 自定义文件夹增删（IMAP CREATE/DELETE）
- [ ] 文件夹树 UI（可折叠、显示未读数）

### 2. 邮件操作
- [ ] 已读/未读：IMAP STORE FLAGS（+/- \Seen），本地即时更新 + 乐观 UI
- [ ] 星标：+/- \Flagged
- [ ] 移动：IMAP COPY 到目标 + STORE \Deleted 源（或 MOVE 扩展，回退 COPY+EXPUNGE）
- [ ] 删除：移入「已删除」；彻底删除 = EXPUNGE
- [ ] 归档：移入「归档」文件夹
- [ ] 标记垃圾：移入「垃圾邮件」
- [ ] 批量操作：多选（Ctrl/Shift）、全选
- [ ] 快捷键：E 归档、# 删除、U 未读、S 星标、R 回复、F 转发

### 3. 多账户
- [ ] 账户切换：切换后列表/文件夹树刷新
- [ ] 统一收件箱可标记来源账户
- [ ] 每账户独立同步状态与文件夹树

## 三、验收标准

- [ ] 移动/删除/星标/归档/垃圾操作后，本地与服务器（网页邮箱）状态一致
- [ ] 批量操作对 ≥100 封邮件正确且不超时
- [ ] 自定义文件夹可创建/删除并同步
- [ ] 多账户切换正常，各账户文件夹与未读数独立正确
- [ ] 快捷键全部可用

## 四、涉及模块

- `src-tauri/src/services/folder_service.rs`、`flag_service.rs`
- `src-tauri/src/commands/folders.rs`、`commands/flags.rs`
- `src/features/folders/`、`src/features/mail/actions.ts`

## 五、风险与注意

- 操作采用「本地乐观更新 + 后台同步 + 失败回滚」，避免操作后 UI 与实际不一致。
- MOVE 扩展并非所有服务商支持，需实现 COPY+STORE+EXPUNGE 回退路径。
- EXPUNGE 会永久删除，需二次确认或可配置。
